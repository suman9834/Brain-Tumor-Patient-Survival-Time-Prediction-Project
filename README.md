# Brain Tumor Patient Survival Time Prediction

## Project Overview
This project is the second project in my 100 Machine Learning Projects challenge, where I am building and documenting different machine learning projects to improve my practical understanding of data science and artificial intelligence.

This machine learning project predicts the survival time of brain tumor patients based on clinical and treatment-related features.  
It uses regression models to analyze patient data and estimate survival time in months.

## Objective
The main goal of this project is to build a predictive model that can help estimate patient survival time using factors such as:
- Age
- Gender
- Tumor type
- Tumor grade
- Tumor location
- Treatment type
- Treatment outcome
- Time to recurrence
- Recurrence site

## Dataset
The dataset contains clinical records of brain tumor patients with features related to diagnosis, treatment, and survival outcome.

### Key Features
- Patient ID
- Age
- Gender
- Tumor Type
- Tumor Grade
- Tumor Location
- Treatment
- Treatment Outcome
- Time to Recurrence (months)
- Recurrence Site
- Survival Time (months)

## Project Workflow
1. Imported and explored the dataset.
2. Checked data structure and summary statistics.
3. Handled missing values and encoded categorical variables.
4. Split data into training and testing sets.
5. Trained multiple regression models.
6. Evaluated model performance using MAE, MSE, RMSE, and R² score.
7. Compared model results and analyzed feature importance.

## Models Used
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score

## Results
The Random Forest Regressor performed better than Linear Regression on this dataset, giving more accurate survival time predictions.

### Best Model
- Random Forest Regressor
- MAE: 1.505850
- MSE: 14.04985
- RMSE: 3.748313
- R² Score: 0.815841

## Key Insights
- Time to recurrence is one of the most important features.
- Age also contributes significantly to prediction.
- Tumor location, tumor type, and treatment outcome influence survival time.
